Музыкальный салон

Консольное приложение для автоматизации работы музыкального салона

О проекте

Приложение предназначено для учета компакт-дисков, треков, операций поступления и продажи. Поддерживает аутентификацию пользователей с разделением ролей (администратор/пользователь), формирование аналитических отчетов и контроль остатков с помощью триггера.
